# Xebia Assignments

This repository contains solutions and projects completed as part of the Xebia assignment series.

## Assignments

### Assignment 1 - Employee Management System

A full-stack Employee Management System built using the MERN stack.

#### Features

* Create Employee
* View Employees
* Update Employee Information
* Delete Employee
* MongoDB Database Integration
* REST API with Express.js
* React Frontend

#### Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* Mongoose
* Axios

#### Project Structure

```text
assignment1/
├── backend/
├── frontend/
└── README.md
```

#### How to Run

Backend:

```bash
cd assignment1/backend
npm install
npm run dev
```

Frontend:

```bash
cd assignment1/frontend
npm install
npm run dev
```

Application URL:

```text
Frontend: http://localhost:5173
Backend:  http://localhost:5000
```
