# Xebia Assignments

This repository contains solutions and projects completed as part of the Xebia assignment series.

## Assignments

### Assignment 1 - Employee Management System

A full-stack Employee Management System built using the MERN stack.

#### Features

* Create Employee
* View Employees
* Update Employee Information
* Delete Employee
* MongoDB Database Integration
* REST API with Express.js
* React Frontend

#### Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* Mongoose
* Axios

#### Project Structure

```text
assignment1/
├── backend/
├── frontend/
└── README.md
```

#### How to Run

Backend:

```bash
cd assignment1/backend
npm install
npm run dev
```

Frontend:

```bash
cd assignment1/frontend
npm install
npm run dev
```

Application URL:

```text
Frontend: http://localhost:5173
Backend:  http://localhost:5000
```

### Assignment 2 - Internship Management Platform

A system design and product documentation project for a centralized Internship Management Platform that connects students, companies, and placement coordinators.

#### Overview

Addresses the problem of fragmented internship discovery and management across email threads and spreadsheets. Covers the full intern lifecycle — from company onboarding and job posting to student applications, interview scheduling, offer dispatch, and completion certificates.

#### Deliverables

* User Roles (Student, Company, Placement Coordinator, Admin, Faculty Mentor)
* Key Features per module
* End-to-end Workflow Diagram and Application State Machine
* Wireframes (Student Dashboard, Company Dashboard, Coordinator Dashboard)
* MVP Definition with Phase 1 scope, Phase 2+ deferrals, and success metrics

#### Tech Stack (Proposed)

* React.js
* Node.js
* Express.js
* PostgreSQL
* JWT Authentication
* AWS S3 / Cloudinary
* NodeMailer / SendGrid

### Assignment 3 - AI-Powered Placement Management Platform

A comprehensive product design and system documentation project for an AI-driven campus placement platform.

#### Overview

Targets the inefficiencies of manual placement processes by integrating AI into resume analysis, job matching, candidate ranking, and interview preparation. Designed for students, recruiters, placement officers, and faculty.

#### Deliverables

* Stakeholder Analysis
* User Stories (Student, Placement Officer, Recruiter, Faculty)
* Product Requirement Document (PRD) with functional and non-functional requirements
* AI Feature Specs (Resume Analyzer, Smart Job Matching, Candidate Ranking, Interview Assistant)
* Feature Prioritization using MoSCoW Method
* Wireframes (Student, Placement Officer, Recruiter Dashboards)
* System Architecture Diagram

#### Tech Stack (Proposed)

* React.js
* Node.js
* Express.js
* PostgreSQL
* OpenAI API
* Sentence Transformers
* LangChain
* AWS / Azure
